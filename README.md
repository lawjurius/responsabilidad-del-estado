## Sobre este manual

Este manual organiza en forma de libro el curso de **Responsabilidad extracontractual del Estado**. Recorre el tema desde sus bases en el derecho civil hasta la acción de repetición contra el agente estatal, siguiendo el orden de las diapositivas del curso.

Se elaboró **exclusivamente a partir del material del curso**: las diapositivas, los apuntes y las exposiciones de clase. Su contenido no proviene de fuentes externas.

Cada tema incluye:

| | |
|---|---|
| **Definiciones** | figuras y conceptos clave |
| **Clasificaciones** | regímenes, tipologías de perjuicios, títulos de imputación |
| **Normas** | Constitución, Código Civil, CPACA, Ley 678 de 2001, Ley 2195 de 2022 |
| **Jurisprudencia** | Consejo de Estado, Corte Constitucional, Corte Suprema de Justicia |
| **Ejemplos y casos** | casos reales y académicos analizados en clase |
| **Fórmulas** | actualización de valores y liquidación del lucro cesante |
